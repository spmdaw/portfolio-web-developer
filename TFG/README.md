
# MoodPlanned

### Aplicación web de planificación basada en el estado emocional

**MoodPlanned** es una aplicación web desarrollada como **Trabajo de Fin de Grado (TFG)** del ciclo de Desarrollo de Aplicaciones Web.

La aplicación permite al usuario descubrir y gestionar planes y actividades según su estado de ánimo, incorporando funcionalidades de usuario, favoritos, valoraciones y gamificación.

## ✨ Funcionalidades principales

* 😊 Selección del estado de ánimo
* 🗓️ Creación y gestión de planes
* 👤 Registro y perfil de usuario
* 🔐 Inicio de sesión
* ❤️ Favoritos
* ⭐ Valoraciones
* 🏆 Puntos y logros
* 📊 Panel principal
